# Shell Exercises

Bash coursework covering variables, expansions, loops, file checks, log parsing, processes, and signals. The numbered files are separate exercises rather than one application.

## Folders

- `init_files_variables_and_expansions/`
- `loops_conditions_and_parsing/`
- `processes_and_signals/`

## Reading and running the exercises

Use Bash on Linux. Many scripts print a result, while others define shell state, start loops, or signal processes. Scripts involving `/proc`, `/var/run`, or system files depend on Linux permissions. Read each file before running it; some exercise commands change files or process state.
